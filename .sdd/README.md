# SDD Directory

## Purpose

Spec-Driven Development methodology files including project constitution that govern how the flight delay prediction system is developed.

## Files

- **`constitution.md`** - Immutable project rules, boundaries, and constraints

## Related Documentation

- **`docs/adr/`** - Architectural Decision Records documenting major design choices

## Usage

- **Start here** for any questions about methodology or project rules
- **Reference constitution** before making structural changes
- **Create ADRs** in `docs/adr/` for significant architectural decisions
- **Validate compliance** using provided validation scripts

## Key Principles

- **Specifications lead implementation**
- **Immutable constitutional constraints**
- **Human-in-the-loop validation gates**
- **Documentation-driven development**
