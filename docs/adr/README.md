# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records documenting significant architectural decisions for the flight delay prediction project.

## What are ADRs?

ADRs capture important architectural decisions along with their context and consequences. They provide:

- Historical record of decision-making
- Context for new team members
- Rationale for architectural choices
- Framework for future decisions

## Integration with SDD

ADRs follow the SDD methodology by documenting decisions made during specification and implementation phases.
